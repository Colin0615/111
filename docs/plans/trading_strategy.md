# $50 实战交易策略手册

## 核心理念
> 小资金的优势是灵活，劣势是容错率低。不追求频繁交易，只打高确定性的仗。

---

## 1. 市场选择优先级

### 第一优先：信息不对称市场 (最高 Edge)
这是 $50 小资金最应该关注的机会：

| 类型 | 为什么 Edge 大 | 例子 |
|------|---------------|------|
| **新上线市场** | 定价不充分，参与者少 | 新创建的政策/事件盘 |
| **冷门市场** | 大资金/机器人不关注 | 小众政策、地区选举 |
| **事件前夜** | 信息即将公布，AI可提前分析 | CPI公布前、政策投票前 |
| **新闻驱动突变** | 突发新闻后市场反应不充分 | 重大声明后1-2小时内 |

### 第二优先：加密货币盘 (最高流动性)
- BTC/ETH 价格预测盘：流动性最好，滑点最小
- 适合练手和验证系统
- **注意**: 这类市场定价已经很高效，edge 通常只有 2-4%
- 建议用 $20 (40%) 在这个类别

### 第三优先：政治/政策盘 (AI 最大优势)
- AI 可以快速阅读和分析大量政策文件、新闻
- 市场参与者往往有情绪偏见 (partisan bias)
- 建议用 $15 (30%) 在这个类别

### 暂时不碰
- **体育**: 需要专业数据，AI 优势小
- **极端概率 (>95% 或 <5%)**: 边际价值太低
- **即将到期 (<24h)**: 风险不可控
- **流动性极低 (<$500/天)**: 进出困难

## 2. 交易决策流程

```
发现机会
    │
    ▼
AI 分析 (Claude Haiku/Sonnet)
    │ 输出: YES 概率 + 置信度 + 推理
    │
    ▼
计算 Edge = AI概率 - 市场价格
    │
    ├── Edge < 8% → 跳过 (不值得冒险)
    │
    ├── Edge 8-15% → 小仓位 $2-3
    │
    └── Edge > 15% → 较大仓位 $3-5
         │
         ▼
    风控检查
    ├── 总持仓 < $40? (留 $10 储备)
    ├── 同类市场暴露 < $15?
    ├── 当日交易 < 3笔?
    └── 全部通过 → 下限价单
         │
         ▼
    人工确认 → 执行
```

## 3. 具体的 AI Prompt 模板

### 快速评估 (Haiku - 低成本)
```
你是预测市场分析师。请评估以下市场:

市场问题: {question}
当前 YES 价格: ${yes_price}
到期时间: {end_date}
市场描述: {description}

请直接输出 JSON:
{
  "yes_probability": 0.XX,
  "confidence": "high/medium/low",
  "key_factors": ["因素1", "因素2"],
  "edge_assessment": "YES价格偏高/偏低/合理",
  "recommendation": "BUY_YES/BUY_NO/SKIP",
  "one_line_reasoning": "简短理由"
}
```

### 深度分析 (Sonnet - 重要决策时用)
```
你是专业的预测市场分析师，擅长概率校准。

## 市场信息
问题: {question}
YES 价格: ${yes_price} | NO 价格: ${no_price}
成交量: ${volume_24h} (24h)
到期时间: {end_date}
详细描述: {description}

## 最新相关新闻
{news_summaries}

## 任务
1. 列出支持 YES 的论据 (至少3个)
2. 列出支持 NO 的论据 (至少3个)
3. 评估新闻对结果的影响
4. 给出你的 YES 概率估计 (精确到1%)
5. 评估你的置信度 (1-10)
6. 与市场价格对比，计算 edge
7. 给出交易建议 (BUY_YES/BUY_NO/SKIP) 和建议仓位

## 特别注意
- 避免确认偏误：认真考虑反方论据
- 考虑基础概率：类似事件的历史概率是多少？
- 考虑时间因素：距离到期还有多久，信息还可能怎么变？
```

## 4. 每日工作流程

### 早间 (10分钟)
1. 检查隔夜市场变动
2. AI 扫描所有关注市场的最新新闻
3. 更新持仓盈亏

### 盘中 (按需)
4. 收到新闻提醒 → AI 快速评估影响
5. 发现高 edge 机会 → 深度分析 → 决定是否交易

### 晚间 (10分钟)
6. 回顾今日交易和 AI 预测准确性
7. 扫描新上线市场
8. 更新交易日志

## 6. 止损和退出规则

| 触发条件 | 行动 |
|----------|------|
| 单笔亏损 > $3 | 检查 AI 分析是否有误，考虑止损 |
| 总亏损 > $10 (20%) | **立即停止所有交易**，回顾分析 |
| 连续 5 笔亏损 | 暂停 2 天，重新评估策略 |
| AI 准确度 < 50% (10笔后) | 调整 prompt 或换模型 |
| Edge 持续 < 5% | 说明市场高效，减少该类别交易 |

## 7. 从 $50 到扩大规模

```
$50 阶段 (1-4周): 验证 AI edge 是否真实存在
    │ 条件: 累计盈利 > $5 (10%+) 且 胜率 > 55%
    ▼
$200 阶段 (1-2月): 增加资金，开启半自动化
    │ 条件: 月化回报 > 10% 且系统稳定
    ▼
$1000 阶段 (3-6月): 完整系统自动化
    │ 条件: Sharpe > 1.5 且最大回撤 < 15%
    ▼
$5000+ 阶段: 专业运营
```
