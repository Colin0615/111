## 数据流

```
新闻发布 → 采集 → 去重/分类 → AI分析 → 概率估计
                                              ↓
市场数据 → 实时监控 → 价格/流动性 → 信号生成 ← Edge = AI概率 - 市场价格
                                              ↓
                                        风险检查 → 仓位计算 → 交易指令
                                              ↓
                                        订单创建 → 签名 → 提交 → 监控
                                              ↓
                                        通知 + Dashboard 更新
```

## 核心交易逻辑

```python
# 简化的核心决策流程
async def trading_loop():
    while True:
        # 1. 获取所有活跃市场的最新数据
        markets = await market_monitor.get_active_markets()

        # 2. 获取最新的 AI 分析结果
        for market in markets:
            ai_prob = await analysis_engine.get_probability(market)
            market_price = market.yes_price

            # 3. 计算 Edge
            edge = ai_prob - market_price

            # 4. 生成信号
            if abs(edge) > MIN_EDGE_THRESHOLD:
                signal = Signal(
                    market=market,
                    direction="BUY_YES" if edge > 0 else "BUY_NO",
                    edge=abs(edge),
                    confidence=ai_prob.confidence
                )

                # 5. 风控检查
                if risk_manager.approve(signal):
                    # 6. 计算仓位
                    size = risk_manager.calculate_position_size(signal)

                    # 7. 执行交易
                    order = await executor.place_order(
                        market=market,
                        side=signal.direction,
                        size=size,
                        price=market_price + slippage_buffer
                    )

                    # 8. 通知
                    await notifier.send_trade_alert(order)

        await asyncio.sleep(LOOP_INTERVAL)
```

## 市场选择策略

### 优先市场类别（按 AI 优势排序）
1. **政治选举/政策** - 新闻驱动，AI 可以快速分析大量政策新闻
2. **经济数据** - 数据公布后的快速反应
3. **加密货币事件** - 链上数据 + 新闻分析
4. **科技行业** - 产品发布、监管决定
5. **体育赛事** - 需要专业数据源，AI 优势相对较小

### 避免的市场
- 流动性极低的市场 (日成交量 < $1000)
- 即将到期 (< 24小时) 的市场
- 结算标准模糊的市场
- 极端概率 (>95% 或 <5%) 的市场（边际价值低）
